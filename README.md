# Sistema de Folha de Pagamento (Console App) 💼

## 📌 Descrição
Aplicação em C# para cálculo simples de folha de pagamento, utilizando entrada de dados via console. Permite simular salário bruto, descontos e salário líquido.

## 🚀 Tecnologias Utilizadas
- C# .NET
- Console Application

## 🧮 Funcionalidades
- Cadastro de funcionário (nome, cargo, salário base)
- Cálculo de INSS e descontos fictícios
- Exibição do resumo da folha no console
- Estrutura modularizada com classes e métodos
